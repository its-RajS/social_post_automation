How to Start the System

cd automation/

# 1. Start infra (postgres, redis, minio, chroma, neo4j)
docker compose up -d postgres redis minio chroma neo4j

# 2. Run DB migration (first time only)
cd nodejs-api && DATABASE_URL="postgresql://user:pass@localhost:5432/linkedin_automation" npx prisma migrate deploy && cd ..

# 3. Start everything
docker compose up --build -d

# 4. Verify

curl localhost:3000/health          # Node API       → {"ok":true}
curl localhost:8001/health          # M1 worker      → {"ok":true,"redis":true,"db":true}
curl localhost:8002/health          # M2 knowledge   → {"ok":true,"db":true,"neo4j":true}
curl localhost:8003/health          # M3 page-analysis → {"ok":true,"db":true}

Trigger Module 2 (Knowledge Graph build):

curl -X POST http://localhost:8002/api/v2/graph/build \
  -H "Content-Type: application/json" \
  -d '{"doc_id": "<uuid from Module 1>"}'

# Check status
curl http://localhost:8002/api/v2/graph/status/<job_id>
# View entities for a doc

curl http://localhost:8002/api/v2/graph/entities/<doc_id>

---
Trigger Module 3 (Page Analysis & Scoring):

curl -X POST http://localhost:8003/api/v3/pages/analyze \
  -H "Content-Type: application/json" \
  -d '{"doc_id": "<uuid from Module 1>"}'

# Check status
curl http://localhost:8003/api/v3/pages/analyze/status/<job_id>

# View all pages with scores
curl http://localhost:8003/api/v3/pages/<doc_id>

# View auto-selected pages (score > 0.7)
curl http://localhost:8003/api/v3/pages/<doc_id>/selected
